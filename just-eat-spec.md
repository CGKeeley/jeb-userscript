This is a bookmarklet for making Just Eat for Business (separate from Just Eat) more usable.

You should develop it using Playwright.

It should produce a button by each day which launches a comparison page.
On the comparison page it should show all items available for that day by querying each meal provider for that day and amalgamating the options
The comparison page should have the option to filter by diet and switch between inclusive or exclusive. For example, it should allow filtering by pescatarian OR vegetarian.
It should sort by price in descending order by default
